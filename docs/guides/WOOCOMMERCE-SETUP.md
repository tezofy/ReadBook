Everything the shop needs, screen by screen. Follow in order.

## 1. General settings

**WooCommerce → Settings → General**

| Setting | Value | Why |
|---|---|---|
| Store address | Your real address | Required by law for tax |
| City / postcode / country | Your real ones | Same |
| Currency | **Euro (€)** | Matches the demo prices |
| Currency position | Right, `€` before | European convention |
| Thousand separator | `.` | 1.234,56 |
| Decimal separator | `,` | 14,99 |
| Number of decimals | `2` | Prices always show cents |
| Units | Weight `kg`, Dimensions `m` | Matches the paperback weights |

## 3. Shipping

**WooCommerce → Settings → Shipping → Shipping options**
- **Default customer address:** Leave as "No default address set" or force it
  to your country so shipping calculates correctly.
- **Shipping calculation:** ☑ *Enable shipping calculations* (even for e-books,
  WooCommerce hides it when the cart is digital-only)

### Zones

**Shipping → Add shipping zone**

**Zone 1 — "Europe"**
- Countries: choose the European countries you ship to
- Add method → **Flat rate** → Title `Shipping`, Cost `4.00`, Tax status `None`

**Zone 2 — "United Kingdom"**
- Countries: United Kingdom
- Add method → **Flat rate** → Cost `6.00`
- *Note: UK orders are outside the EU, so they are usually VAT-free and may
  need a customs declaration. Tell buyers this.*

**Zone 3 — "Rest of World"**
- Countries: everything else
- Add method → **Flat rate** → Cost `9.00`

**Zone 4 — "Digital only"** *(optional)*
- Countries: all
- **Do not add any shipping method**
- This is how e-book-only orders skip shipping entirely.

### The "Other details" table

For each zone, click **Edit → Other details** and set:

```
Default tax status:   Taxable
Default tax class:    Standard
```

## 4. Payments

Enable **at least two** so you never lose a sale to a regional block.

### Stripe

1. Plugin: **WooCommerce Stripe Payment**
2. WooCommerce → Settings → Payments → Stripe → **Manage**
3. Tick **Enable Stripe**
4. Paste **Publishable key** and **Secret key**
5. **Test mode** ☑ → place a test order with card `4242 4242 4242 4242`,
   expiry `12/34`, CVC `123`
6. When the test works, untick Test mode and place a real €1 order

### PayPal

1. Plugin: **WooCommerce PayPal Payments**
2. WooCommerce → Settings → Payments → PayPal → **Manage**
3. **Enable sandbox** while testing, untick for live
4. Sign in with your PayPal **business** account

### Bank transfer (the safety net)

1. WooCommerce → Settings → Payments → **Bank transfers** → ☑ Enable
2. Add your bank details in the instructions field
3. This works with zero setup and no approval — turn it on while your card
   account is being approved

### Direct bank transfer

Same, but in **WooCommerce → Settings → Payments → Direct bank transfer**.

## 5. Emails

**WooCommerce → Settings → Emails** — every email is editable.

### The ones to personalise

**New order** (goes to you)
- Subject: `New order #{order_number} — {order_total} — {customer_name}`
- Body: keep it simple — you want to see what was bought and the billing
  address at a glance.

**Customer invoice**
- This is the one readers see when they are redirected after checkout.
- Add: *"If you have any questions about your order, just reply to this
  email — I read every one."*

**Order confirmation**
- Add: *"Your e-book download link is below. It stays live for 30 days —
  save it somewhere safe."*

**E-book download**
- This is auto-generated by WooCommerce for virtual products. Do not edit it
  much — just add a line about the download window.

### Set the "From" address

**WooCommerce → Settings → Emails → From address** → set to your domain
email (`hello@yourdomain.com`, not a Gmail address). Emails from a free
mailbox land in spam.

## 6. Tax

**WooCommerce → Settings → General → Tax options**

| Setting | Value |
|---|---|
| Enable taxes | ☑ (if you are registered for VAT) |
| Base country | Your country |
| Prices entered with tax | ☑ Include tax in prices as entered |
| Display prices during cart | ☑ Including tax |

**WooCommerce → Settings → Tax → Standard rates**

| Rate name | Rate | Priority |
|---|---|---|
| Standard | Your local VAT % | 1 |
| Reduced | Your reduced VAT % (if books qualify) | 1 |
| Zero | 0% | 1 |

> 📚 **Important for book sellers:** in most EU countries printed books carry
> a **reduced VAT rate** (often 5–10%) while e-books carry the **standard
> rate** (often 19–21%). WooCommerce can handle this — create two tax classes
> and set them per product:
>
> 1. **Products → Edit a book → Product data → General → Tax class → Reduced**
> 2. Leave the paperback at **Standard**
> 3. Create a tax class called `Reduced` in **WooCommerce → Settings → Tax →
>    Tax classes**
>
> Check your local rules — they vary by country and change.

## 7. Email delivery (the step everyone forgets)

By default WordPress sends mail with PHP's `mail()` function, which most
hosts block. Result: no order confirmations, no contact form notifications.

### Fix it with WP Mail SMTP

1. **Plugins → Add New → "WP Mail SMTP"** → install → activate
2. Click the wizard
3. Choose your mailer:

| Mailer | Cost | Notes |
|---|---|---|
| **Brevo** | 300 emails/day free | ✅ Best for a book shop. No per-email fee. |
| **Google / Gmail** | Free | If you use Workspace. Needs OAuth setup. |
| **SendLayer / SMTP.com** | Free tier | Simple, no DNS work needed |
| **Your host** | Included | Ask support for SMTP details |

4. Follow the wizard (it is genuinely click-through)
5. Add the SPF and DKIM DNS records it gives you at your domain registrar
6. **WP Mail SMTP → Email Test** → send yourself one

**Then confirm WooCommerce is using it:**
WooCommerce → Settings → Emails → *New order* → check the "From" address is
your domain address, not a Gmail one.

## 8. Product setup — the exact recipe

### For a book with E-book + Paperback

1. **Products → Add New**
2. **Product data → General**
   - Product type: **Variable product**
   - Regular price: *(leave blank for variable products)*
3. **General → Attributes**
   - Add custom attribute: Name `Format`, values `E-book, Paperback`
   - Tick **Visible on the product page**
   - Tick **Used for variations**
4. **General → Product categories**: E-books + the format category
5. **Variations** → **Generate variations from attributes**

**E-book variation:**
```
Price:            14.99
Virtual:          ✓
Downloadable:     ✓
Downloads:        1
Download limit:   30 days
Download permission:  Only this order
Stock management: ✗ (unchecked)
```

**Paperback variation:**
```
Price:            19.99
Virtual:          ✗
Downloadable:     ✗
Stock management: ✓ → In stock, 999 available
Weight:           0.35
Dimensions:       Length 0.20, Width 0.13, Height 0.02
```

6. **General → Product image**: your cover
7. **Short description**: one punchy sentence
8. **Description**: the full blurb
9. **Publish**

### Per-product fields worth filling in

| Field | Where | Note |
|---|---|---|
| SKU | General | e.g. `VV-EBOOK-01`. Useful for bookkeeping. |
| Featured image | Product image | The cover. |
| Gallery | Product image → Gallery | Back cover, flat-lay, signed copy photo. |
| Series line | Custom field `_nocturne_series` | Shows above the title. |
| Categories | General | E-books / Paperbacks / Limited Editions |

## 13. A quick test order

Before you go live, do this end to end:

1. Open the site in a **private window**
2. Add a book → choose the **Paperback** variation
3. Proceed to checkout
4. Fill in a fake address and a real card:
   - `4242 4242 4242 4242`
   - Expiry `12/34`
   - CVC `123`
5. Place the order
6. ✅ Check the order appears under **WooCommerce → Orders**
7. ✅ Check the **customer invoice** email arrives
8. ✅ Check the **new order** email arrives in your inbox
9. Add a book, choose the **E-book** variation, buy it
10. ✅ Check the **download link** works and the file downloads
11. Refund both test orders

If all eleven points pass, the shop works.

## 14. Legal pages

Create four pages: **Privacy Policy**, **Terms & Conditions**, **Shipping &
Returns**, **Refund Policy**.

You can start from the WooCommerce templates:

**WooCommerce → Settings → Pages → check the boxes next to each → Save changes.**

Then edit each page's text. You will need to fill in:

- Your business name and address
- Your VAT number (if registered)
- Who your processor is (Stripe/PayPal — they are listed as data processors)
- How long you keep customer data (WooCommerce keeps order records by default)
- Your shipping times and costs
- Your return window (14 days is the EU minimum for physical goods)

> If you are in Germany, an **Impressum** is legally required and must name a
> responsible person. If you are in Romania, check what ANPC requires for
> online sellers.

## 15. GDPR cookie banner

The theme includes a lightweight banner, but **Complianz** or **CookieYes**
does it properly with a cookie policy and a way to withdraw consent.

**Plugins → Add New → "Complianz"** → run the wizard → it scans the site and
generates the policy for you.

The theme's own banner (`nocturne_cookie_notice`) can stay as a backup, but
do not run both — pick one.
